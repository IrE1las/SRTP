# S3 前端设计调整

本次依据用户新安装的 `frontend-design` 与 `web-design-guidelines` 调整 S3。另检查了 shadcn 的适用范围：当前项目是 Vue 3 + Element Plus，继续使用已安装的 Vue 组件，避免为界面调整更换框架。

对象是教师出题和铁路站场录制。上一版在同一页面依次展开题库、设置、版本、会话、站场与日志，主要操作距离过远。本次采用独立页面，将设置、操作和核对分开。

```text
操作题库          题目设置             录制答案                检查发布
搜索 / 状态       标题 / 任务 / 班级    题目 / 状态 / 结束按钮   题面 + 发布状态
每页 6 条题目 →   初始站场条件     →   [ 主要空间留给站场 ] →  初始条件 + 目标班级
新建 / 查看       保存 / 保存并录制    功能按钮 / 当前提示      标准答案日志
                                      题干、历史、日志抽屉     发布给目标班级
```

设计取舍：保留原校园深蓝 `#093278`、操作蓝 `#0075b7`，正文 `#19334d`、辅助文字 `#586f82`、边线 `#dfe7ef` 和浅底 `#f5f7fa`。标题采用现有微软雅黑中等粗细，正文沿用系统中文字体；设备编号与次数保持清晰、数字等宽对齐。原站场黑底、信号灯色、轨道光带、站名楷体及设备命中区不改。

最主要的变化是录制时让站场占据窗口主要区域，退出校园页头和侧栏的高度占用；录制之外仍沿用原应用布局。没有添加欢迎大图、装饰数字或不必要的动画。

交互调整包括：班级标签输入、字段旁提示、草稿和下一步分开、未保存离开确认、进行中记录恢复、停止后保存、发布前列出待办、历史版本只读、可折叠日志、显式重录确认，以及空列表与加载失败后的下一步入口。学生页只显示现有 S3 可用内容，不显示开发阶段编号。

组件使用 Element Plus 的表格、表单、输入框、多选、步骤条、提示、弹窗、抽屉和原每页六条分页组件。站场适应窗口的样式只作用于 S3 录制组件；原理论标准站组件及专业引擎未修改。

自检时去除了重复的状态条和站名栏，避免主操作台被说明文字挤压；日志按页读取展示，长题干保留换行、班级和设备名允许换行。口令弹窗使用焦点管理与取消操作，显示缩放和全屏不产生业务点击。取消区间口令时同时清除暂存目标，避免污染后续操作。

本次只做代码检查、无浏览器流程测试与生产构建。未使用浏览器、桌面截图或真实 AI；不把构建通过写成人工视觉验收通过。实际界面请按 `S3_操作验证流程.txt` 查看。
