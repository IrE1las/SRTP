## 启动检查发现的问题及修复

首次启动输出了“Ready”，但随后实际 HTTP 健康接口仍返回 S4，新增服务日志显示端口被占用。检查发现旧项目后端和前端仍在运行；本机 `Get-NetTCPConnection` 未列出它们的监听，不能将该查询无结果当成“没有服务”。原入口只要收到 HTTP 200 就判定就绪，因此误接受了旧服务响应。首次“Ready”不算 S6 启动通过。

已按可执行路径、启动参数及父子关系确认旧进程属于当前项目，随后停止这些旧服务；没有停止其他项目进程。修改原 `启动项目.ps1`：优先检查并复用已保存、仍存活且归属当前项目的服务进程；后端就绪除 HTTP 200 外还需核对 service/status/stage=S6，并再次确认目标进程仍存活。继续使用原入口，没有新增启动模式。
