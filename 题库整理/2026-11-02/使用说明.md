## 文件用途

- `车站联锁六章题库.docx`：含题干、选项、原题图、答案状态和出处的教师整理稿。
- `六章题库.html`：双击后可离线浏览，须与images目录放在一起。
- `六章题库.md`：可继续编辑的文字稿。
- `六章题库.json`：全部206题的主数据；含原题编号、章节、交叉章节、答案、部分答案、来源、图片路径和共用题设。
- `题目索引.csv`：方便筛选的UTF-8索引，兼容Excel。
- `images/`：8张PNG资源；图1-5、1-6、1-7直接从原PDF渲染提取，设备编号未重绘；另5张是原课件核对页。
- `现有接口纯文字草稿.jsonl`：60道有据答案纯文字客观题，逐行对应现有 `POST /api/management/questions` 请求体。
- `导入草稿.py`：调用现有接口创建草稿的辅助脚本；默认只检查本地文件，只有加 `--apply` 才登录并导入。

## 导入现有网站

本次没有改动网站代码、没有写入数据库、没有发布题目。

先启动本项目SRTP的后端，再在本资料包目录打开PowerShell：

```powershell
python .\导入草稿.py
```

该命令只做本地格式检查。需要真正导入时执行：

```powershell
python .\导入草稿.py --apply
```

按提示输入管理员用户名和密码。密码不回显、不保存；脚本仅允许连接本机8000端口。题目导入“自主命题”专题，以六章标签分类，只创建草稿，不自动发布。重复运行按题号标签跳过已存在题目，新增记录存于work/import-journal.json。

60条请求已使用现有后端验证函数做离线格式验证；未进行实际服务器写入验收。现有网站没有通用图片题批量导入入口；本包JSON和图片保留了完整关联，图片题需要接入媒体显示后再导入。原课件整页可能含答案，仅供教师核对，不能直接作为无答案学生题图。

待核对题不在自动导入请求内，不会被伪造答案后发布。保存为草稿后仍需教师检查措辞、体系、年代及答案，再决定发布。
