# 页面宽度核查（2026-11-15）

本次仅在本地修改。公共布局统一管理页面内容区，最大宽度1600px；空间不足时随可用宽度缩小。移除题库、实验专题、学习记录、操作管理、考试管理、个人资料与AI设置各自不一致的页面宽度上限，保留表单内部及图形本身需要的尺寸。公共工作区改用专属类名，避免与实验题目的作答面板混用样式。

## 浏览器结果

59个路由场景分别在2560、1440、1024、390px视口下打开，共236组；登录页另在四种尺寸下检查。当前页面内容区实测如下，同一尺寸下学生、教师和管理员页面一致。

| 视口宽度 | 内容区左边界 | 内容区宽度 |
| --- | --- | --- |
| 2560px | 602px | 1600px |
| 1440px | 276px | 1132px |
| 1024px | 248px | 752px |
| 390px | 16px | 358px |

上述路由场景未发现页面整体横向溢出或脚本异常；宽表格与站场内部保留自身的查看方式。抽查弹窗、密码展开与全屏状态；系统全屏与不支持系统全屏时的页面展开均在四种视口下从(0,0)起，占满对应视口，独立录题操作台也不受普通页面最大宽度限制。交卷结果页另经四种尺寸复验，宽度上限统一为1600px；登录表单保留适合输入的宽度。

前端113项既有测试及Vite生产构建通过。本次验证用临时数据库、账号状态文件、浏览器截图、拼图和脚本在核查结束后清理；不上传GitHub。
