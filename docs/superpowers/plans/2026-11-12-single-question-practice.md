# 章节随机单题练习

用户要求进入客观题库即为六章入口。章节内一次显示一题，提交后即时判分，用绿色/红色反馈答案，错误时展示笔记批注式正确答案；底部提供上一题、下一题、标记题目。

使用独立练习作答表和账号收藏表，不改正式实验与考试成绩。只有明确审核的题号、答案及题面签名匹配时才加入练习池；本批182道可练，其他资料题保留但不猜测判分。独立规则文件为`ai_design/station/chapter_practice_rules.json`。逐空填空按经核对的等价写法匹配，只有并列列举无先后的三道题允许无序匹配；多选采用无序且无重复的精确集合匹配，判断严格识别布尔值False。

每次需要新题时在当前章节随机抽取，上一题返回已抽出的历史题并保留草稿与首次提交结果。重复提交返回首次结果，学生不能读取他人的练习。收藏按用户和题号唯一存储，可以仅练标记题。
