## 解析与 AI 使用

- 上传格式：PPTX、PDF、DOCX、UTF-8 TXT、Markdown，单份最多 40 MB。旧 `.ppt` 先在 PowerPoint 中另存为 `.pptx`。课件和 PDF 最多 1500 页，全文最多 200 万字；解析过程中不执行宏、脚本、外部链接或资料中的指令。
- 加密 PPTX、DOCX 和 PDF 可填写打开密码。密码不写入数据库、文件名或日志；保存的是可读取副本。失败时不会创建资料记录。当前五份旧 PPT 使用本机 PowerPoint 单独完成去密码，不依赖实验性的旧 PPT 解密实现。
- PPTX 按演示文稿中实际的幻灯片次序解析，包含表格和组合形状中的文字；PDF 按页，Word 和纯文本按段落定位。Word 不虚构页码。
- 图片、扫描件、图内文字、电路连线、动画、讲者备注尚未作为 AI 的视觉依据。页面显示文字较少的页数和提取限制；全文无文字的资料显示“文字待补充”，仍可下载和删除。
- 每次 AI 回答重新读取启用资料，按相关文字检索并随来源名称、页码／段落进入生成和审校请求。例如“进路建立包括哪几个阶段”可定位到《16车站信号_1》第70页。停用、改名和删除在后续检索中生效，已有对话中保存的引用保留。
- 本题标准答案和判分结果仍由原规则决定；课程资料用于解释，不改分。铁路专业范围检查继续执行，专业外问题拒答。已核验联锁规则和站场范围继续作为专业约束。

## 数据与部署

新增 `knowledge_documents` 和 `knowledge_migrations` 两张表，资料文字及管理状态存入当前数据库，上传文件存入 `.runtime/knowledge-library/documents/`，由 UUID 命名。接口更新和删除校验版本号，避免旧页面覆盖新修改。

较大上传文件的临时接收缓冲位于 `.runtime/tmp/backend-uploads/`，请求结束自动关闭并删除，不使用系统资料目录长期存放副本。

数据库恢复副本位于 `.runtime/knowledge-library/backups/before-library-20261116.db`。导入与启动后核对既有数据表，行数均未改变，SQLite 完整性检查为 `ok`。恢复或迁移资料库时，数据库与 `.runtime/knowledge-library/documents/` 需要一起备份。恢复副本属于回退资料，应保留。

安装后端依赖使用更新后的 `requirements.lock.txt`。默认无 Office 依赖，网页解析使用 Python 本地库。可通过 `framework/backend/scripts/import_knowledge.py` 显式导入已可读取的文件；重复导入同一文件会跳过，不在启动时扫描用户目录。课件与运行资料已加入 Git 忽略范围，没有上传到 GitHub。
