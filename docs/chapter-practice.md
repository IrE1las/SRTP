# 客观题库自主学习

进入客观题库显示六章入口及当前账号的可练数、已作答数、曾做对数。章节卡片提供作答进度和标记复习入口。进入章节后中间始终只显示一道题，通过上一题、下一题或右侧题号切换，移除整章题目纵向排列及显示方式切换，下方空间留给后续内容。支持单选、多选、判断和逐空填空。

章节页左侧切换章节，中间浏览题目，右侧通过题号自由跳转。无需提交当前题就能进入任意题目；题型、题干/题号搜索可与未作答、尚未做对、曾做对、已标记筛选组合使用。“尚未做对”包括未作答和已作答但从未做对的题目。题号显示本人历史状态，曾做对优先显示绿色；没有提交记录的题目填写部分内容后显示草稿状态，标记以星号显示。手机端章节横向排列，题号导航默认收起，可自行展开。

单题提交后显示正误、标准答案与已有解析，答错自动展开解析。重新练习产生新的独立作答，原有历史与曾做对状态保留。已提交记录和标记随账号保存，重新进入页面可恢复最近一次作答；未提交草稿只保存在当前题库页面的内存中，在本页面内跳题、筛选和切换章节不会丢失，刷新或离开页面后不保留。筛选结果中的题目提交后暂留原位供阅读反馈，重新筛选时更新列表。

## 界面依据与组织（2026-11-16）

交互参考公开教学平台资料中的章节组织和答题卡选题方式。[学习通学生手册](https://www3.xzmu.edu.cn/jwc/userfiles/file/44e94ba7-f33f-47df-abba-a0f2fd9604d9.pdf)介绍了通过答题卡题号跳到相应题目；[中国大学MOOC课程建设指南](https://www.cueb.edu.cn/docs/2023-09/26fd1cb4c39b41fab1cb7a718fc82191.pdf)用于区分课程学习内容与正式测验的用途。本项目据自主学习需求保留自由浏览、单题提交与提交后反馈。

沿用平台的交大蓝白视觉：深蓝 `#093278` 用于现有平台框架，主蓝 `#0075B7` 用于当前章节与主要操作，纸白 `#F5F7FA` 用于页面背景，墨色 `#19334D` 用于正文，绿色 `#237449` 与红色 `#AD413A` 表示作答结果。字体沿用 Segoe UI、微软雅黑与苹方，标题与题干靠字号和字重区分；内容左对齐。章节入口提供进度摘要，练习页以题目阅读区为主体，两侧目录与题号仅承担定位作用。

## 当前练习范围

资料题共366道客观题，其中182道有完整、明确答案且不依赖未展示的题图，已加入即时练习：第一章31、第二章28、第三章29、第四章36、第五章32、第六章26。其他资料题保留，不猜测判分。

`ai_design/station/chapter_practice_rules.json` 为独立的练习判分授权清单。每条规则固定题号、题型、题面/选项/答案/状态的SHA256，题目修改导致签名不匹配时停止出题，须重新审核规则。原题库的正式考核 `auto_score_ready` 标记不被改写。

填空采用规范化后与人工确认的等价写法匹配，识别大小写、全半角和空白；数字/汉字、常见术语等别名在规则中逐项列明，不做任意语义推测。多空默认按题干顺序，仅三道无顺序的并列列举题允许一一无序匹配；多选要求集合准确且不能重复选项；判断必须是明确布尔值，False是有效答案。

## 接口与持久化

前缀 `/api/chapter-bank/practice`，学生、教师和管理员均可练习。

- `GET /chapters`：可练数、资料题总数及当前账号的已作答、曾做对和标记数。
- `GET /chapters/{chapter}/questions`：整章可练题目及本人历史状态，只对本人已提交的作答返回反馈。单纯浏览不创建作答，改题后不恢复旧版反馈。
- `POST /questions/{qid}/attempts`：为指定的可练题目建立独立作答，提交前不返回答案。
- `POST /chapters/{chapter}/draw`：保留原随机接口兼容历史调用；当前学习页面不使用随机抽题。
- `GET /attempts/{id}`：自己的题面及已提交结果。
- `POST /attempts/{id}/submit`：首次提交即时判分；重复提交仍返回首次结果。
- `PUT /bookmarks/{qid}`：标记或取消标记。
- `GET /bookmarks?chapter=1`：当前账号的标记题号。

数据独立保存于 `chapter_practice_attempts` 和 `chapter_practice_bookmarks`，不写入原实验、考试和成绩表。题面与判分规则以私有快照保存；提交前的接口只投影题面字段，用户不能访问其他账号的记录。
