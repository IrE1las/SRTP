# 成员版界面下的录题、考试与账号管理

本次以 `codex/050804Lyz-learning-space-20261114` 的 `03ea375` 为应用基础，按用户要求补回替换前 main（`44e4ba3`）的正式考试、教师录制操作题和账号管理流程。题目资料、专业规则、站场定义以及成员版已有学习功能继续使用成员版本。

## 入口与使用

| 用户 | 入口 | 功能 |
|---|---|---|
| 学生 | 学习空间 | 原六章客观题、六个实验专题和标准站自由仿真 |
| 学生 | 操作与考试 → 操作学习 | 进入教师发布给本人班级的操作题，提交后查看步骤差异与讲解 |
| 学生 | 操作与考试 → 正式考试 | 查看开放时间，申请全屏后开始一次正式考试 |
| 学生 | 历史考试与成绩 | 本人的交卷原因、操作记录及教师已发布成绩 |
| 教师、管理员 | 操作题录制与管理 | 设置题干、目标班级和初始条件，录制标准操作，停止后保存，再检查发布 |
| 教师、管理员 | 操作学习批阅 | 查看学生步骤比对结果、填写评语并确认已查看 |
| 教师、管理员 | 正式考试管理 | 使用已发布的操作题版本安排考试，查看名单、答卷，保存人工成绩草稿或发布成绩 |
| 管理员 | 用户管理 | 建立学生或教师账号，修改身份资料，停用或启用，重置密码，解除联系方式修改锁定 |
| 全部角色 | 个人资料与密码 | 查看身份信息，验证当前密码后修改联系方式或密码 |

成员版的登录、学生/教师自行注册和教学工作台保留。管理员不能通过公开注册创建。停用账号保留历史关联，重置密码、改密、停用和角色改变会使旧登录失效。旧 bcrypt 密码仍可校验，新密码使用兼容的完整密码摘要方案。

## 学习、自由仿真与正式考试的边界

学生在自己的自由仿真会话中可以办理进路、操纵道岔、推进仿真车辆、设置车列/故障占用、设置失表示并恢复设备，也可以模拟邻站输入。其他账号仍不能操作或读取该会话，口令校验、设备条件和联锁拒绝规则保持。

教师录题、操作学习和正式考试使用持久化的独立会话，不受自由仿真的故障设置影响。操作学习沿用确定性步骤比对，完整一致为 100 分，否则展示错误及首个差异，不由 AI 决定分数。六个专题与客观题库的评分规则保持。

正式考试保存发布时的名单、题目版本、标准操作和初始条件，每人一次机会。刷新或断线继续按服务端截止时间计时，服务恢复后补做到期结算；全屏退出记录、待确认操作和重试幂等保护继续保留。考试没有自动评分或 AI 建议分，学生只能看到教师已发布的人工成绩，教师修改草稿期间保留上一版公开成绩。

考试作答页独立占用视口，站场使用题干和计时栏以外的剩余区域。浏览器验收取消固定尺寸模拟后，实际测得页面为 2048×1152，容器边界从 (0,0) 到 (2048,1152)，完整站场保持可见。不同屏幕的具体尺寸随浏览器全屏区域变化。

## 数据与升级

以下记录为此前恢复考试、录题与账号流程时的验证。本次学习空间收拢、标准站适配及最新测试结果见 [学习空间调整](study-space-2026-11-15.md)。

应用注册新增表，同时保留成员版全部模型。已有 SQLite 账号表通过 `account_upgrade.py` 增补缺少的账号字段；更改前保存完整 SQLite 恢复副本至 `.runtime/account-upgrade-backups/`，重复启动不重复升级。旧库的非空学号增加唯一性约束；检测到重复学号时停止升级并提示核对，不自动删除、合并或改写账号。

当前题目范围和记录范围以 `实验专题题库说明.md` 与 `docs/实验专题与学习记录.md` 为准。

已有库若已有专题记录，启动脚本会跳过整批专题初始化。需要补齐成员题目时，先备份并验证副本，再使用既有导入命令：

```powershell
.runtime/venv/Scripts/python.exe framework/backend/scripts/import_lab_topics.py
.runtime/venv/Scripts/python.exe framework/backend/scripts/import_lab_topics.py --apply
```

该命令不会强行覆盖已有作答或管理员编辑的不同题目；遇到冲突应建立版本并复核。数据库和恢复副本仅留在本机，不随 Git 上传。
