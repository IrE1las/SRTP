## 录制与作答协议

设备菜单操作与其他点击一样经过权限、递增序号、事件ID重试校验和封存检查，并写入操作日志。口令不写入日志或浏览器待重试记录。旧版运行状态可在副本中适配独立DG；原日志不改写。人工解锁、引导保持、行车和出清计时支持跨请求恢复，终端别名对应的进路定义也随会话保存。

比对兼容旧中间DA/LA标记及同一设备操作的新旧事件表示；实际按钮、参数或顺序不同仍是差异。已有提交结果保留。操作回放显示当前页面已接收的状态，重新载入后完整业务过程仍以持久化操作日志为准。
